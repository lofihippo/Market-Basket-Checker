# Market Basket brand asset

`market-basket-icon.png` is the unmodified 32 × 32 PNG served as the official
Market Basket site's favicon, downloaded September 14, 2026.

Source: [Market Basket's official site icon](https://www.shopmarketbasket.com/wp-content/themes/market-basket/favicons/favicon.ico),
linked by the [official homepage](https://www.shopmarketbasket.com/).
Despite the remote `.ico` suffix, the response is a PNG. Its bytes are unchanged.

The report embeds the image as a data URL for its header and favicon, so opening
the report offline does not request assets from another site. The dashboard's
other category illustrations are local SVG drawings. The report identifies
itself as an independent flyer companion.
